## สิ่งที่จะได้เรียนในหน้านี้

- CI กับ CD ต่างกันอย่างไร และแต่ละขั้นตอนควรมีอะไรบ้าง
- การสร้าง pipeline ด้วย GitHub Actions
- การรัน test, linting และ build ทุกครั้งที่มี pull request
- กลยุทธ์การ deploy: rolling, blue-green, canary
- การจัดการ secrets และ environment ต่าง ๆ ใน pipeline
