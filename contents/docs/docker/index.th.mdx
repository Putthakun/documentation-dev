## สิ่งที่จะได้เรียนในหน้านี้

- container คืออะไร และต่างจาก virtual machine อย่างไร
- การเขียน `Dockerfile` (รวมถึง multi-stage build สำหรับ Go)
- images, layers, volumes และ networks
- `docker compose` สำหรับ local development stack
- แนวทางเรื่องขนาด image และความปลอดภัย
