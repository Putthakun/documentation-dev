Git คือระบบ version control ที่แทบทุกทีม backend/DevOps ใช้เพื่อติดตามการเปลี่ยนแปลงของโค้ด ทำงานร่วมกัน และ ship งานได้อย่างปลอดภัย ส่วนนี้เป็นคู่มือแบบเน้นตัวอย่างจริง — ไม่ใช่แค่ syntax ของคำสั่ง แต่รวมถึง *ทำไม* คำสั่งเหล่านี้ถึงมีอยู่ และ *เมื่อไหร่* ควรหยิบมาใช้
