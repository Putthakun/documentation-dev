Go เป็นภาษาแบบ statically typed ที่คอมไพล์ล่วงหน้า ออกแบบมาเพื่อสร้าง backend software ที่เรียบง่าย เชื่อถือได้ และมีประสิทธิภาพ ตัวภาษามี feature set ที่เล็กโดยตั้งใจ — คุณสามารถเรียนรู้ทั้งภาษาได้ภายในไม่กี่วัน ซึ่งนั่นคือจุดประสงค์หลัก: มีสิ่งที่ต้องจำน้อยลง มีวิธีเขียนสิ่งเดียวกันน้อยลง และโค้ดยังคงอ่านง่ายเมื่อคนอื่น (รวมถึงตัวคุณเองในอนาคต) เปิดมันขึ้นมาดู

ส่วนนี้ครอบคลุมตัวภาษาเอง ส่วน pattern ที่ idiomatic สำหรับจัดโครงสร้างโปรเจกต์จริงจะอยู่ในหัวข้อถัดไปที่ [Golang Best Practices](/docs/code-organization)
