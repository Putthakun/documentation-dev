## สิ่งที่จะได้เรียนในหน้านี้

- การใช้งาน filesystem, permissions และ ownership
- Processes, ports และการใช้ resource (`ps`, `top`, `lsof`, `netstat`)
- การอ่าน log และค้นหาข้อความ (`grep`, `tail`, `journalctl`)
- การเขียน shell script เล็ก ๆ และใช้ pipe อย่างมีประสิทธิภาพ
- SSH, การโอนไฟล์ และการทำงานบน remote server
