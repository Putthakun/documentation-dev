## สิ่งที่จะได้เรียนในหน้านี้

- เกณฑ์ตัดสินใจระหว่าง monolith กับ microservices
- การสื่อสารระหว่าง service (REST, gRPC, message queue)
- การเป็นเจ้าของข้อมูล (data ownership) และการหลีกเลี่ยง distributed transaction
- Observability ข้าม service
