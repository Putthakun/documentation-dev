## สิ่งที่จะได้เรียนในหน้านี้

- สามเสาหลัก: logs, metrics และ traces
- Structured logging และ log level ที่มีประโยชน์
- Metrics ด้วย Prometheus และ dashboard บน Grafana
- Distributed tracing ด้วย OpenTelemetry
- Alerting: อะไรที่ควรค่าให้ปลุกคนตอนดึก
