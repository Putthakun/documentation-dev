SQL is the language you use to talk to a relational database, and PostgreSQL is the database most backend teams reach for: open source, extremely reliable, and packed with features that let you push work down into the database instead of doing it in application code.

This section covers the SQL you'll write daily and the PostgreSQL specifics worth knowing early. Deeper topics — query plans, JSONB, window functions, schema evolution — live in [PostgreSQL Advanced](/docs/postgresql-advanced), [Query Optimization](/docs/query-optimization), and [Migration Strategies](/docs/migration-strategies).

Every example uses the same small schema — users, orders, and products — so the queries build on each other as you read.
