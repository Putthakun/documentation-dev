SQL คือภาษาที่ใช้พูดคุยกับ relational database และ PostgreSQL คือฐานข้อมูลที่ทีม backend ส่วนใหญ่เลือกใช้: เป็น open source, เสถียรมาก และมีฟีเจอร์เพียบพร้อมที่ช่วยให้เราผลักงานลงไปทำในฐานข้อมูลแทนที่จะทำใน application code

ส่วนนี้ครอบคลุม SQL ที่คุณจะเขียนเป็นประจำทุกวัน และรายละเอียดเฉพาะของ PostgreSQL ที่ควรรู้ตั้งแต่เนิ่นๆ ส่วนหัวข้อที่ลึกขึ้น — query plan, JSONB, window function, การเปลี่ยนแปลง schema — อยู่ใน [PostgreSQL Advanced](/docs/postgresql-advanced), [Query Optimization](/docs/query-optimization) และ [Migration Strategies](/docs/migration-strategies)

ทุกตัวอย่างใช้ schema เล็กๆ ชุดเดียวกัน — users, orders และ products — เพื่อให้ query ในแต่ละหน้าต่อยอดกันไปเรื่อยๆ ขณะที่คุณอ่าน
